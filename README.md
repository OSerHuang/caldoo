离线优先的 Android 饮食记录应用：拍照或文字记一餐，自动算热量与盐分，数据全部存在手机本地。

## 功能

- **记一餐**：拍照（AI 识别）或打字 / 键盘麦克风语音输入；在概览翻到过去的日子
  可直接补记（餐次可改）；AI 失败也不影响保存
- **修改记录**：餐食详情里点 编辑 可改食物与餐次，也能改**用餐日期和时间**
  （记错时间直接挪到正确的那一天）；详情页标题下显示这条记录的时间
- **食物库**：营养成分表拍照自动建档，一图可含多个标签；所有食物可搜索、复用，
  营养数值可随时编辑，并可选择把已记录的餐次一并按新数值重算
- **概览**：日 / 周 / 月热量与盐分，滑动翻看历史；每日运动消耗手动记录
- **每日热量目标**：在 我的 → 每日热量目标 设定（预设档位或自定义）；预设档位存的是
  「相对基础代谢的差值」（−250 / −500 / +250），体重变化后基础代谢重算，目标与每日额度
  会自动跟着变；自定义大卡则是固定值、不随体重变。每日额度 = 目标 + 运动，环心标注
  缺口 / 盈余相对额度，周 / 月汇总看热量达标天数
- **体重记录**：概览日页的体重卡（今天显示最新值，翻到过去某天则显示当天的记录、
  当天没记就不显示）、周 / 月的体重折线块和完整趋势页；记录会同步资料 → 我的
  里的体重，基础代谢随之重算
- **数据本地 + 自动备份**：全部数据只存本机，并自动备份到公共目录
  `Download/caldoo/`（保留最近 10 份），在 我的 → 数据备份 恢复。升级安装请用
  原地覆盖，**不要先卸载再安装**（会清空数据）
- **显示单位**：大卡 ↔ 千焦、盐 ↔ 钠，随时切换，只影响显示

## 配置 AI（BYOK）

分析由你自己的 API Key 驱动，Key 存在系统安全存储里，不落数据库、不进日志、不进备份。

1. 打开 **我的 → 设置 → 模型设置**
2. 粘贴 API Key（`sk-...`）→ **保存**，可用 **测试连接** 验证
3. 默认端点：`https://api.deepseek.com` + `deepseek-flash`；任何 OpenAI
   兼容端点都可以在设置里覆盖
